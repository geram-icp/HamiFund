## Core Rules
- HamiFund Core never imports GERAM internal types.
- External systems connect only through versioned adapters/contracts.
- Wallet is not a Financial Account.
- Token is not the underlying real asset.
- AI is decision support, not authority.
- Ledger changes are event-driven and auditable.
- Sensitive financial commands must be idempotent.
